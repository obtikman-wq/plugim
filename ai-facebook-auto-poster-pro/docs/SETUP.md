# Setup Guide — AI Facebook Product Auto Poster Pro V3.0

## Requirements

- WordPress 6.0+, PHP 8.1+
- WooCommerce 7.0+ (products, prices, stock, categories)
- An SSL (https) site — Meta OAuth and webhooks require it
- PHP `gd` extension for the built-in Poster Designer (non-AI fallback)
- Optional: WooCommerce Action Scheduler (ships with WooCommerce) for the most reliable queue

## Installation

1. In WordPress go to **Plugins > Add New > Upload Plugin** and upload `ai-facebook-auto-poster-pro.zip`.
2. Activate the plugin. On activation the plugin creates its database tables (schema v3) and schedules its background tasks.
3. Upgrading from V2: settings, pages, schedules, queue, history, and analytics are preserved. `DB::maybe_upgrade()` runs `dbDelta` migrations safely on admin load.

## Quick start

1. **Facebook Connection** — enter your Meta App ID + App Secret, save, then click **Connect Facebook account** and approve the permission dialog. Your accessible Pages load automatically with name, ID, profile image, and page access tokens (encrypted with AES-256-GCM).
2. Tick the Pages you want to post to and click **Save page selection**.
3. Choose a **posting mode** on the Direct Auto Posting tab:
   - **AI Mode** — captions generated by OpenAI / Gemini / a custom OpenAI-compatible API.
   - **Direct Mode** — captions built from live WooCommerce product data. No AI API needed, no AI costs.
   - **Both Modes** — run both engines independently with separate schedules. If an AI call fails and "AI fallback to Direct" is on, the post still publishes via the Direct engine.
4. Create a **schedule** (fixed times, multiple times per day, weekly days, random time windows, category filters, per-schedule product selection method and pages) or use **Bulk scheduling**.
5. Watch the **Post Queue**, **Post History**, **Analytics**, and **Marketing Calendar** tabs.

## Cron reliability

The plugin uses Action Scheduler when available and falls back to WP-Cron (custom `aifbp_5min` interval). For high-volume sites set a real cron:

```
*/5 * * * * curl -s https://example.com/wp-cron.php?doing_wp_cron > /dev/null
```

If `DISABLE_WP_CRON` is defined, the **System Status** tab shows a warning. Cron health (next runs, lateness) is displayed under **System Status** and the Dashboard.

## Data & privacy

- Page tokens, App Secret, and AI API keys are stored encrypted (AES-256-GCM, `wp_salt('auth')` key) and never displayed in full.
- Data retention: posted queue rows and logs older than the configured number of days (Tools tab, default 90) are cleaned automatically.
- Assistant privacy option restricts what is sent to AI providers (product titles/prices only).
- Uninstall removes all plugin tables and options.
